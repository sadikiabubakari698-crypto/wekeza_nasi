# WEKEZA NASI — SYMBOLS & VISUAL LANGUAGE SYSTEM

Version 1.0 — Foundation

## 1. LOGO

Symbol: Chipukizi (young sprout with one leaf)
Wordmark: WEKEZA NASI
Tagline: Jifunze. Wekeza. Kua Mtaji wa Maisha.

## 2. CORE SYMBOL SYSTEM (5-stage, locked)

1. Chipukizi — Taarifa mpya
2. Mche — Hatua mpya ya kujifunza
3. Mti — Umefikia hatua kubwa
4. Tunda — Mafanikio maalum
5. Taji — Mchango kwa jamii

## 3. SUPPORTIVE SYMBOLS

- Wazo — AI pillar
- Malezi — Academy pillar
- Jamii — Community pillar
- Fursa — opportunity/market
- TSh Thamani — financial value
- Ukuaji — general growth (only where none of the 5 Core stages apply)

RETIRED: Mbegu (conflicts with Chipukizi), Mavuno (conflicts with Tunda)

## 4. RULES

No generic emoji icons anywhere in the product. Only symbols above. Use plain numbering (01, 02...) until custom icon files exist.
